# 繁體中文介面

Windows 介面預設為台灣繁體中文。設定頁的「介面語言」可切換 `繁體中文（台灣）`／`日本語`；偏好保存在同一 Hub 網址的瀏覽器 `localStorage`，不需新增正式環境依賴。

主畫面、設定、對話操作、角色標籤、GitHub、整理／還原、子作業移交／整合、用量與空白作業清理採靜態語言檔。既有主機診斷、CLI 輸出與自訂內容保留原文。原生 Codex 指示新增預設繁體中文回報規則，使用者指定的其他語言優先。

`public/i18n.js` 的 `L` 只查詢明確文案；`UI` 只翻譯程式碼的固定 HTML／文字片段與顯示屬性。插入的專案名稱、標題、路徑、使用者內容、AI 回覆與 HTML 都視為不透明值，由原有 `esc`／格式化流程處理。介面翻譯不重寫資料檔，`data-*`、API 名稱、狀態與角色識別值保持原值；顯示已翻譯標籤的選單保留明確 `value`。

切換語言前保留目前頁面位置。有尚未儲存的角色／CLI 模型設定時會先提示；取消則保留目前語言與草稿。語言檔型別、大小、UTF-8 或保留標記檢查失敗時停用控制項並顯示錯誤。

驗證：`node --test test/i18n.test.js test/i18n-main.test.js test/i18n-aux.test.js`。測試實際 renderer、原值 API 綁定、日文復原、偏好保存、取消切換、不透明值與損壞語言檔的拒絕路徑。另以合成本機專案進行實際瀏覽器的繁中→日文→繁中切換；未送出模型提示或修改真實使用者資料。這些語言驗證不代表完整 Hub 資安或安裝驗收。
